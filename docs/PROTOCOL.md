# CQM1 协议

## 数据帧

```text
<CQM1|5H=78|5HR=1788966311|W=87|WR=1789448757|RC=3|NOW=1788958655|TZ=480>\n
```

字段含义：

| 字段 | 含义 | 约束 |
|---|---|---|
| `5H` | 5 小时窗口剩余百分比 | 0..100，必需 |
| `5HR` | 5 小时重置 Unix 秒 | uint32，必需；0 表示不可用 |
| `W` | weekly 窗口剩余百分比 | 0..100，必需 |
| `WR` | weekly 重置 Unix 秒 | uint32，必需；0 表示不可用 |
| `RC` | reset cards | `-1` 表示不可用，缺失也按不可用 |
| `NOW` | 发送时刻 Unix 秒 | uint32，必需 |
| `TZ` | 发送端 UTC 偏移，分钟 | -1440..1440，必需 |

百分比是 `100 - usedPercent`，Bridge 只在 provider 成功得到合法快照后发送。`resetsAt` 的单位是 Unix seconds。

## 解析规则

- 字段允许乱序；未知字段忽略。
- 必需字段缺失、整数非法、quota 越界、timestamp 溢出、TZ 越界时整帧拒绝。
- 同名字段重复时整帧拒绝，不采用最后一个覆盖规则。
- 错误帧不得覆盖上一份有效状态。
- 接收端按换行切帧，单帧最大 255 字符。

## 退出帧

```text
<CQMQUIT>\n
```

目标源代码同时保留历史兼容命令 `<Quit>\n`。退出帧不进入 quota parser。
