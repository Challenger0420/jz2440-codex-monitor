# Windows Bridge 自启动计划（仅设计）

未来优先使用当前用户上下文的 Task Scheduler，在用户登录后启动 Bridge；本轮不创建任务。

计划要求：

- 使用当前用户环境，以便访问 Codex 登录状态。
- 使用无 GUI 的 Bridge 进程。
- 参数采用自动发现；只有现场稳定后才考虑固定 `--port` override。
- 日志放在用户可写的明确目录，并按日期轮转。
- Bridge 任意一次 provider、COM、写入或拔插失败都进入日志→等待→重试。
- 任务设置 crash 后重启，但不能并发启动多个 Bridge 实例。
- 停止/卸载任务必须是明确、可逆的人工操作。

正式实施前仍需确认 Codex CLI 登录上下文、日志目录权限、重复实例锁和退出行为。
